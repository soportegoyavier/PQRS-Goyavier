🔗 Conexión con Google Sheets

¿Cómo conectar con Google Sheets y Google Forms?
  1. Cree un Google Forms con los campos requeridos.
  2. Vincule el Forms a un Google Sheets.
  3. En el Sheets, vaya a Extensiones → Apps Script.
  4. Pegue el script de integración (ver botón abajo) y haga clic en Implementar → Nueva implementación (tipo: Aplicación web · ejecutar como usuario que accede · acceso restringido al dominio Workspace).
  5. Copie la URL de implementación y configúrela abajo.
🔒 Endpoint fijo — no requiere configuración manual.

🔑 Inicio de sesión con Google (institucional)

El acceso al sistema es exclusivamente mediante cuenta Google. Solo los correos registrados en la hoja UsuariosPQRS del Sheets pueden ingresar. Cada usuario debe tener un Perfil en esa hoja: Secretaria (ve padres de familia y estudiantes), Talento Humano (ve colaboradores, proveedores/contratistas y visitantes) o Rectoria (ve todo). Para agregar o quitar usuarios edite esa hoja directamente; para crear las columnas nuevas ejecute actualizarEstructura() en Apps Script.

¿Cómo configurar el inicio de sesión con Google?
  1. Vaya a Google Cloud Console → Credenciales → Crear credencial → ID de cliente OAuth 2.0.
  2. Tipo de aplicación: Aplicación web. En Orígenes autorizados: https://script.google.com y https://script.googleusercontent.com.
  3. Copie el ID de cliente, edite el HTML y establezca la constante GOOGLE_CLIENT_ID con ese valor.
  4. Ejecute actualizarEstructura() en Apps Script para crear/actualizar la hoja UsuariosPQRS (columna Perfil) y luego complete usuarios, claves y perfiles directamente en la hoja.

🏢 Gestión de Áreas / Dependencias

Agregue, edite o elimine dependencias. Cada área puede tener un correo para notificaciones.

📬 Avisos por perfil

Cada solicitud nueva (y cada observación, cierre o respuesta de un área) se avisa solo al correo de su bandeja: Secretaría para padres de familia y estudiantes; Talento Humano para colaboradores, proveedores/contratistas y visitantes. Rectoría recibe copia solo cuando llega una solicitud nueva. Si un correo queda vacío, el aviso llega al correo de Secretaría.
